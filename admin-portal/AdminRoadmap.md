# 管理后台实施路线

## 阶段 A：后台项目骨架

目标：
- 在 HBuilderX 中新建独立 `pictographic-admin` 项目。
- 确认它是 Web 管理后台，不是微信小程序页面。
- 先本地运行后台页面和录入流程；等页面和字段稳定后再购买/绑定 uniCloud 服务空间。

验收：
- HBuilderX 可以单独打开后台项目。
- 后台项目可以本地运行到浏览器。
- 本地原型不依赖 `uniCloud`，不要求已经购买服务空间。
- 小程序 `miniapp-uni/word-app1/pages.json` 没有任何后台入口。

## 阶段 B：管理员登录和权限

目标：
- 接入管理员登录。
- 只有管理员角色可以访问后台页面。
- 普通用户无法注册成管理员。

验收：
- 未登录访问后台会跳到登录页。
- 非管理员账号不能进入内容管理页。
- 管理员账号可以进入单词列表。

## 阶段 C：单词内容管理

目标：
- 能新增和编辑单词主卡片。
- 能编辑大段释义字段。
- 能编辑拆解卡片 `parts`。
- 能保存 `draft` 草稿。

验收：
- 后台新增一个 `memory` 草稿。
- 校验通过后可以改为 `published`。
- 小程序读取已发布内容后，搜索 `memory` 能看到词卡。

## 阶段 D：视频片段和资料管理

目标：
- 能录入视频地址、开始秒数、结束秒数、片段标题。
- 能在详情页显示“本词视频片段”的基础信息。
- 后续再做播放器跳转和重放本词。

验收：
- 后台能保存视频片段字段。
- 校验脚本能拦截 `startSec >= endSec` 的错误。
- 小程序不会因为没有视频字段而白屏。

## 阶段 E：缺词反馈闭环

目标：
- 小程序用户提交缺词反馈。
- 后台查看反馈列表。
- 管理员把有效反馈转成待补充词条。

验收：
- 反馈列表能看到 `missingWord`、页码提示、备注、提交时间。
- 管理员能把反馈标记为 `accepted`、`rejected` 或 `published`。

## 安全检查清单

- 后台不注册进用户小程序路由。
- 后台页面不靠隐藏 URL 保护，必须有登录和角色权限。
- 数据库写权限只给管理员。
- 小程序只读 `published` 内容。
- 草稿内容不能被小程序普通用户搜索到。
- 管理员操作后要保留更新时间和操作人字段。
